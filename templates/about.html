About Fish Detection System

The project focuses on developing a fish detection system using advanced object detection models based on the YOLO architecture. By utilizing deep learning models — specifically YOLOv11 and YOLOv9 — the system is designed to accurately detect and classify fish species in underwater images and video streams.

The models are trained on a diverse dataset containing various fish species from different marine environments, enabling robust performance in challenging underwater conditions such as varying lighting, water clarity, and fish movement.

A user-friendly web application built with Python Flask serves as the main interface, offering features including user registration, login, image upload, and real-time live video detection. The platform delivers instant species identification, bounding box visualization, and confidence scores directly in the browser.

This project aims to provide an efficient, accurate, and scalable tool for marine researchers, conservationists, and aquaculture professionals, contributing to the monitoring, study, and preservation of marine ecosystems through state-of-the-art artificial intelligence.
